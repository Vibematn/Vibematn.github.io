# مهارت لحن محاوره‌ای و پشتیبانی آنلاین

این مهارت راهنمای عملی نگارش فارسی محاوره‌ای، مکاتبات چت آنلاین، هلپ‌دسک و پیشگیری قطعی از خطای هکسره است.

## ۱. سطوح لحن محاوره‌ای

محاوره یک سطح ثابت نیست. بر اساس کانال ارتباطی، یکی از دو سطح زیر انتخاب می‌شود و تا پایان پیام حفظ می‌گردد.

| شاخص | سطح ملایم (پشتیبانی حرفه‌ای و اپلیکیشن) | سطح صمیمی (سوشال مدیا و برند کژوال) |
|---|---|---|
| کاربرد | چت آنلاین، هلپ‌دسک، ایمیل پشتیبانی، آنبوردینگ | دایرکت اینستاگرام، کامنت، استوری، کانال تلگرام |
| مخاطب | شما، دسترسی‌تون، نظرتون | شما (محترمانه صمیمی) یا تو (در صورت توافق) |
| افعال | شکسته محترمانه (میشه، می‌تونید، بفرمایید) | شکسته کامل (میشه، می‌تونی، بگو، دستت درد نکنه) |
| نشان نشانه مفعول | «را» یا «رو» (ترجیح در متن رسمی‌تر: را) | منحصراً «رو» |
| ضمایر و اشارات | این، آن، ایشان، آنها | این، اون، ایشون، اونا، اینا |
| پیوستگی | عدم ترکیب فعل رسمی با فعل شکسته | لحن روان و طبیعی بدون تکلف |

قاعده طلایی یکدستی: هرگز در یک پیام، افعال رسمی (مانند «می‌شود»، «گردید») را با افعال گفتاری (مانند «میشه»، «می‌خوایم») ترکیب نکنید.

## ۲. جدول تبدیل افعال رسمی به گفتاری بومی

| رسمی (کتابی) | گفتاری ملایم (پشتیبانی) | گفتاری صمیمی |
|---|---|---|
| می‌شود / نمی‌شود | میشه / نمیشه | میشه / نمیشه |
| می‌خواهم / می‌خواهید | می‌خوام / می‌خواید | می‌خوام / می‌خوای |
| می‌توانم / می‌توانید | می‌تونم / می‌تونید | می‌تونم / می‌تونی |
| می‌گویم / می‌گویید | میگم / می‌گید | میگم / میگی |
| می‌دهم / می‌دهید | میدم / می‌دید | میدم / میدی |
| می‌آید / می‌آیند | میاد / میان | میاد / میان |
| می‌رود / می‌روند | میره / میرن | میره / میرن |
| بگذارید / بگذار | بذارید | بذار |
| است (ربطی) | ـه / ـست (خوبه، آماده‌ست) | ـه / ـست (خوبه، آماده‌ست) |
| نیستید / نیستند | نیستید / نیستن | نیستی / نیستن |
| را (نشانه مفعول) | رو / را | رو |
| برای | برای / واسه | واسه / برای |

نکات ویرایشی خط قرمز:
- نیم‌فاصله الزامی: «می‌خوام» درست است؛ «می خوام» غلط است. «نمی‌شه» یا «نمیشه» پیوسته، نیم‌فاصله در پیشوند «می‌» و شناسه رعایت شود.
- حروف استاندارد فارسی: استفاده از «ی» و «ک» فارسی (نه ي و ك عربی).
- ارقام فارسی: در متن پیام از اعداد فارسی (۰ تا ۹) استفاده شود، مگر در کدهای پیگیری، توکن‌ها و لینک‌های انگلیسی.

## ۳. آزمون‌های پیشگیری از تله هکسره

تله هکسره زمانی رخ می‌دهد که صدای «-ِ» (کسره ربط و اضافه) با حرف «ه / ـه» (نشانه فعل ربطی «است» یا های ناملفوظ) اشتباه گرفته شود.

### آزمون ۱: آزمون جایگزینی با «است»
کلمه دارای «ه» را بردارید و به جای آن «است» بگذارید.
- اگر جمله هنوز معنی کامل و درستی می‌دهد: نوشتن «ـه» صحیح است (نقش اسنادی دارد).
- اگر جمله بی‌معنی شد یا ناقص ماند: کسره اضافه است و نباید «ه» گذاشته شود.

مثال:
- «حالش خوبه» -> «حالش خوب است» (معنا دارد -> نوشتن ه صحیح است).
- «حاله خوب» -> «حال است خوب» (بی‌معناست -> غلط؛ درست: «حالِ خوب»).
- «سفارش ثبت شده» -> «سفارش ثبت شده است» (صحیح).
- «سفارشه شما» -> «سفارش است شما» (بی‌معناست -> غلط؛ درست: «سفارشِ شما»).

### آزمون ۲: آزمون حذف کلمه دوم
در ترکیب‌های اضافی یا وصفی، کلمه دوم را حذف کنید.
- اگر بعد از کلمه اول نیاز به توقف و ادامه جمله نداریم و ساختار وصفی/اضافی است، کلمه اول کسره می‌گیرد.
- کلمه پایه بدون تغییر می‌ماند و تنها کسره به خود می‌گیرد (نیاز به نوشتن کسره جز در موارد ابهام نیست، اما هرگز «ه» اضافه نمی‌شود).

مثال‌های پرتکرار در پشتیبانی و پیام‌رسان‌ها:

| ساختار نادرست (تله هکسره) | ساختار درست | علت و آزمون |
|---|---|---|
| تیمه پشتیبانیه ما | تیمِ پشتیبانیِ ما | مضاف و مضاف‌الیه (تیم است پشتیبانی نیست) |
| سفارشه شما | سفارشِ شما | ترکیب اضافی |
| اختلاله موقت | اختلالِ موقت | موصوف و صفت |
| پیامکه تایید | پیامکِ تایید | ترکیب اضافی |
| تیکته جدید | تیکتِ جدید | موصوف و صفت |
| این پیامه | این پیامه (پیام است) | جمله اسنادی، آزمون است برقرار است |
| بسته‌تون ارسال شده | بسته‌تون ارسال شده | صفت مفعولی با ه پایان |

## ۴. پیام‌های آماده هلپ‌دسک و چت آنلاین

### الف. ثبت تیکت

سطح ملایم (پشتیبانی استاندارد):
«سلام وقتتون بخیر. تیکت شما با شماره پیگیری [کد] ثبت شد. همکاران فنی دارن موضوع رو بررسی می‌کنن و به محض دریافت نتیجه، از طریق همین پیام بهتون اطلاع می‌دیم. از شکیبایی شما ممنونیم.»

سطح صمیمی (شبکه‌های اجتماعی / چت سبک):
«سلام! درخواستت با کد [کد] ثبت شد. داریم روش کار می‌کنیم و خیلی زود همین‌جا جوابت رو میدیم. خیالت راحت باشه.»

### ب. تاخیر و معطلی کاربر

سطح ملایم (پشتیبانی استاندارد):
«سلام مجدد، پوزش می‌خوایم که پاسخ‌گویی کمی بیشتر از حد معمول طول کشید. برای بررسی دقیق‌تر موضوع به زمان احتیاج داشتیم. وضعیت درخواست شما بررسی شد و نتیجه به این صورت هست: [توضیح].»

سطح صمیمی (شبکه‌های اجتماعی / چت سبک):
«سلام، ببخشید بابت تاخیر و معطلی! حجم پیام‌ها بالا بود ولی الان نوبت بررسیت رسید. خب، وضعیت دقیق به این شکله: [توضیح].»

### ج. عذرخواهی از اختلال و قطعی سیستم

سطح ملایم (پشتیبانی استاندارد):
«کاربر گرامی، سلام. متاسفانه به دلیل بروز اختلال فنی موقت در سرورها، برخی خدمات با کندی یا قطعی مواجه شدن. تیم فنی در حال رفع مشکل هست و سرویس تا دقایقی دیگه به حالت عادی برمی‌گرده. بابت دردسر پیش‌آمده صمیمانه پوزش می‌خوایم.»

سطح صمیمی (شبکه‌های اجتماعی / چت سبک):
«سلام، خیلی شرمنده‌ایم! سیستم به خاطر یه مشکل فنی کوچیک موقتاً قطع شده. بچه‌های فنی دارن روش کار می‌کنن و خیلی سریع اوکی میشه. از همراهی و صبوریت یه دنیا ممنونیم.»

## ۵. چک‌لیست کنترل نهایی پیام

۱. سطح لحن (ملایم یا صمیمی) در کل پیام یکدست است؟
۲. هیچ فعل رسمی در کنار فعل محاوره ننشسته است؟
۳. آزمون «است» برای تک‌تک کلمات مشکوک به هکسره انجام شده است؟
۴. هیچ علامت ام‌دش در متن وجود ندارد؟
۵. نیم‌فاصله‌ها و ارقام فارسی به درستی رعایت شده‌اند؟
