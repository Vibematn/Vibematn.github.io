## قابلیت‌های کلیدی

۱. **موتور پالایش بلادرنگ (۰ میلی‌ثانیه):**
   - حذف خودکار افعال فسیل اداری («می‌باشد»، «می‌گردد»، «به شمار می‌رود»).
   - پاکسازی فیلرهای زائد («لازم به ذکر است»، «شایان ذکر است»).
   - نیم‌فاصله‌سازی دقیق پیشوندها و پسوندها بر اساس مصوبات فرهنگستان و ابرابزار ویکی‌پدیا.
   - تبدیل ارقام انگلیسی به فارسی با جداکننده هزارگان و واحد تومان.
   - حذف کامل خط تیره بلند (ام‌دش).

۲. **پیش‌نمایش تفاوت هوشمند (Diff View):**
   - نمایش خط‌خوردگی قرمز برای کلمات ماشینی حذف‌شده.
   - هایلایت سبز نئونی برای واژگان بازنویسی‌شده انسانی.
   - سنجش درصد بهینه‌سازی حجم و تعداد کاراکترها.

۳. **کالبدشکافی زبان محصول ۹ پلتفرم بزرگ ایران:**
   - دیجی‌کالا، اسنپ، بلوبانک، دیوار، باسلام، تپسی، کافه‌بازار، فیلیمو، زرین‌پال و زیبال.

۴. **پوشش ۱۴ مهارت رسمی وایب‌فارسی:**
   - هماهنگ با اکوسیستم [vibefarsi.ir/skills](https://vibefarsi.ir/skills) برای ادیتورهای Claude Code، Cursor و Codex.
